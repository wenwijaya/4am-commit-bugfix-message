A program that writes one commit message: the note an AI agent would leave in the log after a long night of chasing down and fixing its own bugs. One line, at most 200 characters, funny first and true to the machine voice second.

The entry it writes (124 characters):

> fix: deleted the bug I wrote at 2am, the fix I wrote at 3am, and most of my confidence — tests pass, and I am not asking why

## Run it

```sh
node main.ts
```

This writes the commit message to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when that variable is set, for local runs).
